Detailed Description

This class represents a piece of memory.

Supports two modes:

  • Owning mode: holds a shared_ptr<Bytes> for lifetime management.
  • Non-owning (view) mode: holds a raw pointer to external data. The caller must ensure the underlying memory outlives this segment.
